# Lantern Harbor v1

An original synthetic Chinese story and illustrative graph annotations created
for this repository's team playground. No text, names, model responses, database
records or embeddings were copied from the private commercial-novel experiments.

The fixture text and its illustrative annotations are offered under the
[CC0 1.0 dedication](https://creativecommons.org/publicdomain/zero/1.0/).
Application code retains the repository's MIT license. This dedication does not
apply to any user-supplied books or private experiment outputs.

## Contents and provenance

- Two chapter sections, eight scenes, three characters and two locations.
- Authored multi-person dialogue cards; no sentence-level speaker benchmark.
- Deterministic sentence IDs generated by the production sectioner.
- Event order, participation, presence, locations and one acquaintance relation.
- No invented model activity, extraction receipts, approval decisions or causal
  certificates. The snapshot is an illustrative fixture, not a successful Pi run.

This is a UI/developer starter, not independently adjudicated ground truth and
not evidence of model accuracy, recall, cost or full-volume stability. Agent mode
uses the same source in a separate fresh database and performs real extraction
only after the user sends a message. Its output may differ from these annotations.

The preparation script writes hashes, schema and code provenance into a private
runtime manifest. Rebuild the disposable native graph on the target platform;
do not distribute a Mac `.lbug` file as a portable dataset.
