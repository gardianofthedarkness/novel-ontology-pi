Causality — links that cross scenes

status: implemented repo: src/solidifier/causality/ · src/ground/connectors/embeddings.ts model: Jev over hybrid search · threshold 0.85

The value is cross-scene causality across the same universe. Scene-local causes were structurally unrepresentable as links — extraction could only list them — so this faculty determines causality at birth and in a chapter-close sweep, and stores it as real CAUSES links. Dialogue is the same type as event in the search: both are uniform search units, and a stored link can end on a dialogue card.

InputsNew units (events + dialogue cards) × the universe, per block; plus a chapter-close sweep over everything the block pass missed

Design details

  • Hybrid search, Jev decides: candidates come from two legs — graph patterns (Cypher) plus embedding similarity (top-32, floor 0.5) — capped at 500 pairs per pass. Jev judges each pair; a link is proposed only at causal ≥ 0.85 AND succession ≤ 0.5 (decision #23). Contradictions hold and are never proposed.
  • Two paths, one machinery: (a) systematic Jev-determined causality at birth — per-block new units × universe, plus the chapter-close sweep; (b) a main-agent-callable add-causality path after a full run. Both propose through the existing gate and apply path.
  • Extraction's causes field is removed: it was scene-local before, and scene-local causes are exactly what cross-scene causality is not. Extraction proposes events; this faculty proposes links.
  • Novel sequence is the timeline for v1: no universe timeline faculty was built in this pass — ordering for succession comes from novel sequence, and a universe timeline faculty comes later (see 11).
  • Scoped lift of the embeddings deferral: graph-first (decision #4) still governs retrieval generally — but causality requires an embedding leg, so the deferral is lifted for causality only. Default is a lightweight local CPU model (~500–1000 dims); model + dimension live in the embeddings manifest (ontology/embeddings.jsonl sidecar), and changing models triggers reindex, not silent corruption.
  • Universe scope is one file for v1: within one novel file, the hybrid search runs over the whole universe. Cross-file links are a separate system with a separate ledger (10a): name-hint nomination only, no embedding leg, book databases never fused.
  • Where the arrows live (owner decision, 2026-10-26): book-level causal arrows are drawn in Story time mode only, not in Narrative views — reversing the earlier Narrative-orbit arrows by design. The inspector still lists causes and effects, and library/series overviews keep their cross-volume arrows.

Implementation

  • src/solidifier/causality/ — nomination, Jev sweep, gate proposals; src/ground/connectors/embeddings.ts — the embeddings sidecar.
  • CLI: novel causality candidates|propose|sweep. Skill reference: skills/novel-ontology/references/causality.md.
  • Rendering: the Story spiral (13) draws every stored link as a lane-routed arc; dialogue-card endpoints project onto their containing spheres.

Open questions — causality

  • Real cross-scene data.Stated honestly: cross-scene arcs and portal arrows have been tested with fixtures only. One real volume's 143 stored links are all intra-scene; another has none. No real-data cross-scene arc has been seen yet.
  • Universe timeline faculty.Succession still rides on novel sequence. A universe timeline faculty (explicit/relative time nodes + constraints) is the later build that replaces it (see 11).
  • Embedding model for production.Local CPU is the default; whether a user-provided embedding API ever joins the sidecar is undecided.
